# 2026-11-01 · F-77 Data model (foundation)

**Scope (owner-approved):** the foundation only. The five wired tables, the conventions every later table must follow, and an append-only audit log. Domain tables (events, quotes, payments and so on) arrive with the features that use them.

**What changed**
- Migration `20261101020000_f77_data_model.sql`:
  - `houses` (kind host/vendor): one of each per account, plus a `(id, kind)` key that other tables can reference to pin the house kind.
  - `memberships`: a composite foreign key `(house_id, house_kind)`. Host houses have owners only. Staff can never hold payouts, members or billing. There is one active owner per house and one active membership per person per house, and every revocation records who revoked it.
  - `staff_grants`: platform staff capabilities with a scope, expiry and revocation. No one can grant themselves a capability, and event managers are always scoped to events.
  - `assignments`: a composite foreign key `(staff_grant_id, target_kind)` means a grant can only be used on the kind of target it's scoped to.
  - `audit_events`: append-only. Updates, deletes and truncates are blocked, and clients can't read it.
  - Shared `app_private.touch()`: `created_at` can't change, `updated_at` updates itself, and `version` goes up on every write. `users` now uses it too.
  - RLS on everything, with no direct client writes. People can read only their own houses, memberships, grants and assignments. `public.my_houses()` is the only cross-table projection.
  - `ensure_user()` now provisions the Host house and owner membership on first admission, and audits it.
- Web: the session loads `my_houses()`. The house shell shows the user's house name, or an empty state when they have no house of that kind.
- `supabase/tests/schema_conventions.test.sql` checks every public table, including future ones. It requires a uuid `id`, timestamptz only, money as bigint `*_minor` plus a currency column, RLS forced, no client writes, no anon reads, and created_at/updated_at/version columns.

**How it was checked**
`bash supabase/tests/run-local.sh` passes the F-76, F-77 and schema-convention tests. `npm test` passes all 19 tests, and the build stays within the bundle budget (78 kB).
